# Assignment 6 — jQuery

Student: Ismail Shargazin
Group: SE-2529

This project demonstrates jQuery selectors, effects,
DOM manipulation and animations.

## Pages

- index.html — Tasks 0–1: setup, selectors and CSS.
- effects.html — Tasks 2–4: visibility, fade and slide methods.
- dom.html — Tasks 5–7: lists, attributes and form interaction.
- animations.html — Tasks 8–10: basic, sequential and combined animations.
- gallery.html — Task 11: interactive sneaker gallery.

## How to run

1. Download or clone the repository.
2. Open index.html in a browser.
3. Use the navigation menu to switch between pages.

An internet connection is required because jQuery loads from a CDN.
